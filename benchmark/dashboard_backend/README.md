# Dashboard backend

FastAPI wrapper around `benchmark/src/ensemble.py` (see docs/04-dashboard.md).
Serves precomputed benchmark results and a paced replay of precomputed,
pre-scored dataset rows. Never runs live PyOD inference on request and never
accepts user-submitted data for scoring.

## Run locally

```bash
cd benchmark
.venv/bin/pip install -r dashboard_backend/requirements.txt
.venv/bin/python run_benchmarks.py   # generates results/*.json + dashboard_backend/data/*.json
cd dashboard_backend
../.venv/bin/uvicorn app.main:app --reload --port 8000
```

Set `ALLOWED_ORIGINS` (comma-separated) to the frontend's origin(s); defaults
to `http://localhost:5173` for local dev.

## Deploy (Render)

`render.yaml` in this directory defines a free-tier web service. After the
frontend is deployed and you know its final URL, update `ALLOWED_ORIGINS` in
the Render service's environment variables to match it exactly (no
wildcards — docs/04-dashboard.md's CORS guardrail).

`dashboard_backend/data/*.json` and `../results/*.json` must exist before
deploying (generated by `run_benchmarks.py` — commit them, they're small
precomputed artifacts, not secrets).
